Voice Counter Ko Kaise Use Karein?

Is voice counter ko use karne ke liye pehle input box mein woh naam ya mantra likhein jise aap count karna chahte hain.

Step-by-Step Method

  1. Jap ya naam input box mein likhein.
  2. Multiple names ko comma se separate karein, jaise: ram, raam.
  3. Apni speech ke according Hindi ya English language select karein.
  4. Start Listening button press karein.
  5. Microphone permission aaye toh browser mein permission allow karein.
  6. Naam ko clear voice mein bolna shuru karein.
  7. Practice complete hone par Stop press karein.

Reset Kaise Karein?

Agar aap count ko zero se start karna chahte hain, toh Reset button press karein. Reset karne se saved count remove ho jaata hai.

Speech recognition browser aur device ke according different behave kar sakta hai. Agar feature work na kare, updated Chrome ya Edge browser try karein.
